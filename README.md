# Тепло Петра

Сайт магазина бытовых газовых котлов и запчастей в Оренбурге.

## Импорт в Lork

В Lork выберите импорт проекта из GitHub и вставьте ссылку на этот публичный репозиторий. Проект соответствует текущему контракту импорта: React + Vite, корневые `package.json` и `index.html`, точка входа `src/main.jsx`. Next.js, серверные функции и переменные окружения не нужны.

## Локальный запуск

```sh
npm ci
npm run dev
```

Сборка: `npm run build`. Каталог результата: `dist/`.

## Что работает

- Адаптивная страница, мобильное меню и FAQ.
- Поиск по названию, модели и артикулу, фильтрация по категориям.
- Подробная карточка каждого из 12 товаров с фото и маркировкой.
- Переход в профиль MAX магазина, звонки и маршрут в Яндекс Картах.
- Включённые локальные фотографии. Шрифт Manrope загружается из Google Fonts; при отсутствии сети используется Arial.

Заявки отправляются непосредственно через MAX. Формы с фиктивной отправкой, база клиентов и онлайн-оплата отсутствуют.

## Редактирование

Тексты и контакты: `src/main.jsx`.
Товары, цены, маркировки и пути к фото: `src/products.json`.
Оформление: `src/style.css`.
Изображения: `public/images/`.

## Источники и границы данных

Материалы: https://yandex.ru/maps/org/228414350464/ — проверено 27 октября 2026 года.

Контакты и график взяты из карточки магазина. Каталог содержит 12 конкретных товаров из витрины магазина: с исходными названиями, фотографиями и маркировками. Источник отмечает прайс как давно не обновлявшийся; на сайте это явно указано. Цены и наличие требуется подтвердить перед покупкой.

Фотографии взяты из карточки компании по просьбе заказчика использовать её материалы. Каждый товар сопровождается своей фотографией из витрины магазина. Фотография системы отопления используется в блоке подбора котла; она не является предложением конкретной модели в наличии.
